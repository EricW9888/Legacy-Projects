# Maze Solver (BFS)

- Language: Python (pygame)
- Completion date: April 2023

Breadth-first style maze explorer that tracks branches concurrently. Uses the same ASCII map format (start `!`, end `*`, walls "#"), keeps a queue of active positions, and renders progress until the exit is found.

## Run
- Install `pygame` (e.g., `pip install pygame`).
- Run from anywhere: `python3 main.py` (script now sets its working directory automatically).
