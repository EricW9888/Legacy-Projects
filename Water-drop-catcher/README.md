# Water Drop Catcher

- Language: Python (pygame)
- Completion date: April 2022

Arcade catcher made with Pygame. Slide a cup to snag falling droplets; standard drops are 1 point, golden drops are 5 points. Three lives total, with speed ramping up over time.

## Run
- Install `pygame` (e.g., `pip install pygame`).
- Run from anywhere: `python3 main.py` (script now sets its working directory automatically).
