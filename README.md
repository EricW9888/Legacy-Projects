# Legacy Projects (archived Replit work)

Old Python projects exported from Replit. This branch keeps the source as-is for reference; no active maintenance. Project code and per-project screenshots are tracked together.

## Quick start
- Requires Python 3.8–3.11.
- Most games/visualizers use `pygame`; install with `pip install pygame`.
- Run from inside a project folder: `python3 main.py`.
- Tkinter apps ship with the standard library on Windows/macOS; Linux may need `sudo apt-get install python3-tk`.

## Project list and completion dates
- `False-Binary-encoder-with-user-interface` — Jan 2023 — Tkinter encoder/decoder that shifts ASCII codes, reverses/rotates bits, and uses a two-digit key. Screenshot: `encoder.png` (keep on an image branch).
- `Floppy-fish` — Dec 2022 — Pygame side-scroller; steer a fish through pipes with W/S or arrows. Screenshot: `fish.png`.
- `Floppy-fish-2` — Apr 2023 — Sequel with jump controls and 5 lives. Screenshot: `fish2.png`.
- `maze-solver-dfs` — Apr 2023 — Pygame depth-first/backtracking maze solver visualizer. Screenshot: `maze.png`.
- `maze-solver-bfs` — Apr 2023 — Pygame breadth-first style maze explorer. Screenshot: `maze2.png`.
- `Neo-Pong` — Sep 2022 — Two-player Pygame pong with sounds. Screenshot: `pong.png`.
- `Water-drop-catcher` — Apr 2022 — Pygame catcher with golden drops worth 5 points. Screenshot: `catcher.png`.
- `Single-Player-Neo-Pong` — Completion date not recorded — Solo pong versus an AI paddle using the same assets as `Neo-Pong`.
- `Bubble-sort-visualization` — Completion date not recorded — Pygame visualization highlighting active comparisons with timing and comparison count.
