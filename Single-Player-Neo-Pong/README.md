# Single Player Neo Pong

- Language: Python (pygame)
- Completion date: February 2023 (approximate)

Solo pong variant where you control one paddle while an AI tracks the ball on the opposite side. Forked from the two-player `Neo-Pong` (September 2022): the assets, sounds, and `sprites.py` are identical, and the Player 1 keyboard branch was replaced by ball-tracking logic with a small random handicap re-rolled on each serve. Use W/S or the arrow keys.

## Run
- Install `pygame` (e.g., `pip install pygame`).
- Run from anywhere: `python3 main.py` (script now sets its working directory automatically).
