# Single Player Neo Pong

- Language: Python (pygame)
- Completion date: Not recorded

Solo pong variant where you control one paddle while an AI tracks the ball on the opposite side. Shares assets and sound effects with the two-player `Neo-Pong` project.

## Run
- Install `pygame` (e.g., `pip install pygame`).
- Run from anywhere: `python3 main.py` (script now sets its working directory automatically).
