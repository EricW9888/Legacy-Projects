# Floppy Fish

- Language: Python (pygame)
- Completion date: December 2022

Pygame side-scroller where you steer a fish up/down through pipe gaps using W/S or arrow keys. Three lives, +1 point per cleared pipe set, and collisions cost a point; speed ramps up over time.

## Run
- Install `pygame` (e.g., `pip install pygame`).
- Run from anywhere: `python3 main.py` (script now sets its working directory automatically).
