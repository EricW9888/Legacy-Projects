# Maze Solver (DFS)

- Language: Python (pygame)
- Completion date: April 2023

Pygame depth-first/backtracking maze solver. Builds walls from the ASCII map (start `!`, end `*`, walls "#"), tracks visited coordinates, and renders the traversal path as it searches for the exit.

## Run
- Install `pygame` (e.g., `pip install pygame`).
- Run from anywhere: `python3 main.py` (script now sets its working directory automatically).
