# Floppy Fish 2

- Language: Python (pygame)
- Completion date: April 2023

Sequel with space-bar jump controls. Five lives, +1 point per cleared pipes, collisions subtract a point, and game speed accelerates as you survive. New fish and pipe sprite variants in `images/`.

## Run
- Install `pygame` (e.g., `pip install pygame`).
- Run from anywhere: `python3 main.py` (script now sets its working directory automatically).
